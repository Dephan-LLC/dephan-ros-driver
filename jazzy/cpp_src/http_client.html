class HttpClient

Small blocking HTTP/1.0 client used by LiDAR web API CLI commands.

HttpClient intentionally implements only the subset needed by the driver command-line interface: GET, POST with a JSON body, and streaming GET for server-sent events or binary downloads. It does not handle authentication, redirects, TLS, chunked transfer encoding or persistent connections.

Public Functions

HttpClient(std::string host, int port = 80, int timeout_ms = 3000)

Create a client for a LiDAR HTTP endpoint.

Parameters:

  • host – LiDAR host name or IP address.

  • port – TCP port of the LiDAR HTTP server.

  • timeout_ms – Socket connect, send and receive timeout in milliseconds.

Throws:

std::invalid_argument – if host is empty, port is outside the TCP range or timeout_ms is not positive.

Parameters:

HttpResponse post(const std::string &path, const std::string &body) const

Execute a blocking HTTP POST request with a JSON body.

Parameters:

  • path – Absolute request path beginning with ‘/’, for example “/config/motor_speed”.

  • body – Raw request body. For configuration writes this must already be a valid JSON token such as “10”, “true” or “"INFO””.

Throws:

  • std::invalid_argument – if path is not absolute.

  • std::runtime_error – or std::system_error on transport or response parsing errors.

Returns:

Parsed HTTP response.

HttpResponse stream_get(const std::string &path, std::ostream &body_stream, std::ostream *status_stream = nullptr) const

Execute a GET request and write the body as it is received.

This method is used for endpoints where buffering the complete response is undesirable, such as the Safety zones SSE stream and LUT binary download.

Parameters:

  • path – Absolute request path beginning with ‘/’.

  • body_stream – Stream that receives response body bytes.

  • status_stream – Optional stream for printing the HTTP status line.

Throws:

  • std::invalid_argument – if path is not absolute.

  • std::runtime_error – or std::system_error on transport or response parsing errors.

Returns:

Parsed HTTP status and headers. The body field is empty because bytes are forwarded to body_stream.

struct HttpResponse

Parsed HTTP response returned by HttpClient requests.

The client stores the status code, reason phrase, raw response headers and response body separately. The status line is normalized into status_code and reason; headers do not include the trailing CRLF separator.
