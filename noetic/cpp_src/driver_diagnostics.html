std::string dephan_ros::diagnostic_hardware_id(const std::string &source_ip, const std::string &pcap_path, const std::string &http_host)

Select a stable hardware identifier for UDP or PCAP diagnostics.

Parameters:

  • source_ip – Configured UDP source filter.

  • pcap_path – Configured PCAP path, empty in UDP mode.

  • http_host – LiDAR HTTP address used when UDP source filtering is off.
